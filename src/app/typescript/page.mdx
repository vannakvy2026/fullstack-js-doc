# TypeScript Course Overview

Welcome to the **TypeScript module**. TypeScript is a strongly typed programming language that builds on JavaScript, giving you better tooling and compile-time checks.

TypeScript adds optional static typing to JavaScript, transpiling down to vanilla JS.

---

## Core Topics

In this module, you will learn:
* **Static Typing**: Declaring types, interfaces, and custom types.
* **Generics**: Creating reusable, type-safe structures and functions.
* **Mapped & Conditional Types**: Constructing dynamic utility types.
* **tsconfig Configuration**: Optimizing your project build settings.

---

> [!NOTE]
> TypeScript helps you catch errors in your IDE during development, rather than waiting for runtime crashes.
