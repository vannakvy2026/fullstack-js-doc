# Node.js Course Overview

Welcome to the **Node.js module**. Node.js is an open-source, cross-platform JavaScript runtime environment that executes JavaScript code outside a web browser, built on Chrome's V8 engine.

Node.js uses an event-driven, non-blocking I/O model that makes it lightweight and efficient.

---

## Core Topics

In this module, you will learn:
* **Event Loop**: Understanding Node's asynchronous runtime loop.
* **Core Modules**: Working with `fs`, `path`, `http`, and `events`.
* **Streams & Buffers**: Handling binary data and streaming files efficiently.
* **REST APIs with Express**: Building server-side backends.

---

> [!NOTE]
> Node.js allows us to use JavaScript as a unified programming language on both the client and server side.
