# Next.js Course Overview

Welcome to the **Next.js module**. Next.js is a powerful React framework that enables server-side rendering (SSR), static site generation (SSG), and edge middleware capabilities.

This documentation site itself is built using Next.js 16!

---

## Core Topics

In this module, you will learn:
* **App Router**: Dynamic routing, layout nesting, and page file conventions.
* **React Server Components (RSC)**: Optimizing loading speeds by executing components on the server.
* **Server Actions**: Handling mutations, form submissions, and database connections.
* **Turbopack & React Compiler**: Utilizing the new performance optimizations in Next.js 16.

---

> [!NOTE]
> Next.js provides the complete fullstack runtime needed to deploy applications directly to production.
