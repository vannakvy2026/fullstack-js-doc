### Code Example

Here is a simple example showing how lexical state is preserved:

```javascript filename="closure-example.js"
function makeCounter() {
  let count = 0; // State variable enclosed by makeCounter
  
  return function increment() {
    count++; // Accesses parent environment's scope
    return count;
  };
}

const counter = makeCounter();
console.log(counter()); // Output: 1
console.log(counter()); // Output: 2
```

In the example above, `increment` maintains a reference to the `count` variable declared in `makeCounter`'s environment long after `makeCounter` has returned.
