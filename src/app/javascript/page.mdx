# JavaScript Course Overview

Welcome to the **JavaScript (JS) module**. JavaScript is a high-level, single-threaded, garbage-collected programming language that conforms to the ECMAScript specification.

This course is structured to teach you both fundamental mechanics and advanced execution contexts.

---

## Core Topics

In this module, you will learn:
* **Lexical Scope & Closures**: How the JavaScript engine resolves variable accessibility.
* **Asynchronous Flow**: Callbacks, Promises, and `async/await`.
* **Prototype Chain**: Prototypal inheritance and execution contexts.
* **Modern ESNext**: Features like modules, destructuring, and optional chaining.
